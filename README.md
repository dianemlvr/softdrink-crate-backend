# Softdrinks Delivery and Crate Tracking System (Backend)

Backend Api for managing softdrinks deliveries, reusable crate tracking, crate returns, and pickup requests for Logistics Managers, Delivery and Recovery Drivers, and Store Owners.

# Tech Stack
-NestJS
-TypeORM
-MySQL
-JWT Authentication

# Running Locally
1. Install dependencies: 'npm install'
2. Configure environment variables in '.env'
3. Start the development in the development mode: 'npm run start:dev'
